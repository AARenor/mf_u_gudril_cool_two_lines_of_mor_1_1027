# u-gudril-cool-two-lines-of-morning-light-ade94fc5

A program that writes one short text for make.fun's bounty `u-gudril-cool-two-lines-of-morning-light-ade94fc5`, where entrants submit a two-line micro poem about light and morning and an AI judge compares poems in pairs. The text here is about a cat, a square of morning light, and how both of them move — or refuse to.

```text
The cat has not moved since six.
The square of light has, and takes her with it.
```

Run `MAKEFUN_OUTPUT_DIR=out python3 main.py` to write the text to `out/entry.txt`.
